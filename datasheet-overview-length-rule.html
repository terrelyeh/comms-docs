Overview 能寫多長？

Datasheet 封面的 Overview 跟 Features 共用一塊版面空間，所以「能寫多少字」是動態算的，沒有一刀切的字數上限。這份文件給 PM / MKT 一個簡單的安全字數參考，以及超出時系統會怎麼提醒。

TL;DR
📌 五件事先記住
  • 沒有固定字數上限，因為 Overview 跟 Features 共用同一塊空間，是動態算的
  • 安全字數（features 量中等時）：英文 ≈ 800 字，日文 / 繁中 ≈ 600 字
  • 超過會顯示紅點和警告橫幅，但不會擋 PDF 生成
  • 確認版面 OK 可按「Mark as Reviewed OK」消除提醒
  • 每個語言獨立判斷：英文沒紅燈不代表日文也沒事
為什麼沒有固定字數上限？

Cover 頁的版面結構

封面從上到下分三個區塊：上方是固定的產品圖，下方是 Features，中間是 Overview。Features 先佔空間（最多 320pt），Overview 拿剩下的。所以 features 越多，overview 能放的越少。

核心規則：Features 先佔，Overview 拿剩下的。

同一頁的空間是固定的，所以你寫越多 features，留給 overview 的位置自然越少 — 反過來也一樣。

這也是為什麼系統不能給你一個「上限 N 字」的數字。

翻譯小提醒：同樣意思翻譯成日文 / 繁中後，會比英文佔更多排版空間，建議翻譯後的字數比英文版本少一些。

為什麼 CJK 比英文緊？

每個語言用不同的字級和行高排版：

Locale 字級 行高 每行能塞的字
English11pt15pt54 chars
日文11.5pt17pt46 chars
繁中12pt18pt44 chars

中日字符在計算寬度時當作 2 個 char slot（雙寬字符），所以同樣意思的句子翻成 CJK 後，行數會明顯增加，更容易撞到 features 區的邊界。

超出會怎樣？

系統不會直接擋你，是用「警告 + 確認」的方式提醒：

  1. Dashboard 對應 OV 欄位顯示紅點 — 一眼看到哪個 model 的 overview 超出了。
  2. Product 詳細頁出現紅色警告橫幅 — 告訴你哪個語言超出、超出多少。
  3. 不會擋 PDF 生成 — 你還是可以正常按 Generate / Regenerate，但建議先預覽確認版面。
  4. 看過覺得 OK → 按「Mark as Reviewed OK」 — 紅燈消失，Dashboard 和詳細頁恢復正常。
  5. 內容一改紅燈會自動回來 — 系統用 hash 追蹤 overview / features，內容變動時 Mark 自動失效，避免「之前 ack 過後來改了沒人知道」。
