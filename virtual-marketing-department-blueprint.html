虛擬行銷部門 AI Agent 參考架構藍圖

一套可重複部署、再依客戶客製的「AI 行銷部門」。底盤統一(Paperclip 治理 + Hermes 員工 + MCP/Skills 能力),客製只動三個旋鈕。給 AI FDE 進客戶現場用 —— 標準化架構,把客戶 know-how 變成 skills。

📅 2026-06-03 🧑‍💻 AI FDE / 部署者 🏗️ Paperclip · Hermes · MCP
核心心法

每進一家客戶不重寫系統,只調三樣。標準化架構是底盤,skills 是你的核心交付物與 IP。

  1. Skills — 把客戶流程、品牌語氣、SOP、定位封裝成 skills;每客戶一個私有 repo / Hermes tap,可版本控管、遠端更新。
  2. MCP 接線 — 接客戶既有工具棧(CRM、分析、廣告後台)。
  3. 組織設定 — Paperclip 的 org chart、各職位 persona、預算上限、審批關卡。
三層架構總覽

治理層管「有哪些員工、各自預算、做得對不對」;員工層是會做事的 agent;能力層是各職位的專業。

層角色工具
治理層主管 / HR / 財務Paperclip(org chart · 預算 · 審批 · 稽核)
員工層各職位 agentHermes(常駐 · 模型不限 · Skills 系統)
能力層各職位專業客製 skills + 客戶 MCP + Claude World Studio MCP

編組關係

Paperclip(治理層:org chart / 預算上限 / 審批 / 稽核) ├── 產品行銷 Hermes + 定位 skills ├── SEO Hermes + SEO skills + Ahrefs/Search Console MCP ├── Digital Hermes + campaign skills + HubSpot/GA MCP ├── Content Hermes + 品牌 skills + 內容 MCP ├── 廣告專員 Hermes + 廣告 skills (預算上限由 Paperclip 鎖) └── 影片製作 Hermes + Remotion/NotebookLM MCP ▲ 行銷總監(human + orchestrator):派工、審核、人類把關
6 職位編制

每個職位 = 一個常駐 Hermes agent,掛上對應 skills 與客戶 MCP。注意每個職位的審批點。

跨職位協作流程

定位先行,內容與廣告都吃同一份定位,Digital 統整成效回饋形成閉環。

產品行銷(定位) │ 定位卡 / Message Guide (品牌單一事實來源) ▼ SEO ── 關鍵字地圖 + 內容 brief ──▶ Content / 影片(產出內容) │ ▼ 廣告專員(受眾 + 文案 + 出價建議) │ 人類核可後投放 ▼ Digital(統整 campaign + UTM 追蹤) │ 成效回饋 ▼ 產品行銷(迭代定位) ◀── 閉環
治理層(Paperclip)與紅線

Paperclip 負責什麼

org chart6 職位 + 回報給「行銷總監(human)」
預算上限每個 agent 設月預算上限,超支自動暫停(廣告專員尤其重要)
審批關卡對外發布、廣告花費、網站結構改動
稽核immutable audit log,所有決策與 tool call 可追溯
品牌來源全部 content / 影片 agent 吃同一份 message guide + .impeccable
幫別人建,特別要顧的四條紅線:
  • 花錢 / 投放絕不自動化 — 一律走人類審批,合約寫清責任歸屬。
  • 資料與密鑰隔離 — 每客戶獨立部署,各自 API key 走 secrets 管理。
  • 成熟度風險 — 工具都還新,先 pilot 一個職位再擴成整個部門。
  • 品牌一致性 — 同一份品牌 skill,避免多 agent 風格分裂。
導入路線

分階段,不要一步到位。先把一個職位跑出成效,再擴編,最後才疊治理層。

Phase 1 · Pilot

單一職位驗證

挑 1 個高價值職位(SEO 巡檢 或 Content 選題),用 Hermes + 客製 skill 跑出成效。

Phase 2 · 擴編

串起協作流程

加到 3–4 個常駐職位,讓定位 → 內容 → 成效的流程跑起來。

Phase 3 · 治理

疊上 Paperclip

org chart、預算上限、審批、稽核,交付客戶可自行操作的 GUI。

FDE 可重複資產(Starter Kit)
📦

把第一次做的沉澱成模板

之後每客戶 fork 再客製
org 模板6 職位 + 預算 / 審批預設
skill pack6 職位通用 baseline skill,客戶版覆寫
MCP playbook常見平台(HubSpot / GA / Ahrefs / 廣告後台)怎麼接
交接資產Discovery 問卷 + 交接文件模板
你 FDE 真正在賣的不是工具 —— 是「把客戶 know-how 變成 skills + 把流程變成 org / 預算 / 審批設定」的能力。
