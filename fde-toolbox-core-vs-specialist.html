FDE 工具箱 核心 vs 專用

用 AI agent 幫客戶建置/代營運時,哪些工具天天用(核心),哪些看情境才拿(專用),以及各自的觸發訊號。核心 = Paperclip + Claude Code + Obsidian;Hermes / CWS 是按需點召的專用工具。

📅 2026-06-07 🧑‍💻 AI FDE 🇹🇼 台灣 · SMB 客群

紅線 + 給台灣 SMB 的建議
  • 別預先導入 —— 沒具體客戶需求或自己的重複痛點,先不裝。
  • 每多一工具 = 多一份維運面(各自跑、各自更新、各自接金鑰)。
  • 成熟度風險 —— 都還新,押客戶 production 前先在自己/EnGenius 驗過。
給你的客群:① Hermes 第一個值得加 —— 台灣愛 LINE,「用 LINE 跟 agent 對話」好賣又有感。② CWS 先別整套 —— 記住「借 MCP」,接到內容/影片重的客戶再用。

一句話:核心永遠 Paperclip + Claude Code + Obsidian;Hermes 在「要排程/要 LINE」時加,CWS 在「內容/影片重」時(優先借 MCP)加。
