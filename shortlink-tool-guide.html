工具定位

一句話：短網址 + UTM + 點擊分析，三件事揉在一個工具裡，讓行銷團隊不用翻 Bitly + Google UTM Builder + GA 三個地方才能追蹤一條活動連結。

跟 Bitly 的差別

  • 用自家網域 go.engenius.ai（不是 bit.ly），對外更可信
  • UTM 規範內建 + 白名單強制（避免同事各打各的 facebook / Facebook / FB）
  • Campaign 是一級公民（不只是 UTM 字串），可以群組、設目標、看時序
  • 免費且無連結上限

5 分鐘上手：建你的第一條連結

  1. 登入：Google OAuth 用公司 email。第一次使用要先拿到管理員給的邀請連結，點開用公司 Google 帳號登入就會自動加入工作區。
  2. 左側 Sidebar → 連結管理
  3. 右上角藍色「+ 建立新連結」（一次要建很多條，按它旁邊的 ▾，見一次建很多條）
  4. 填三個核心欄位：目的地網址、標題（例：Spring 2026 EDM top banner）、UTM 活動（Campaign）。剩下的 source / medium / content 從下拉選單選即可（有常用模板也可以一鍵帶入，非必要）。
  5. 建立 → 直接拿短網址和 QR：建立成功後頁面會直接顯示短網址（按「複製」）和 QR Code（可下載）。要再建同一組 UTM 的連結，按「再建一條（保留 UTM 與標籤）」；之後在列表上，短碼旁的 ⧉ 也能複製。
  6. 貼到你的通路（EDM / FB / IG / LinkedIn / QR 傳單皆可）
  7. 24 小時後看數據：在連結列表直接點那條連結的點擊數，就會打開它的數據分析（預設看全部期間）。

列出工作區裡所有人建的連結，這頁是最常來的地方。

搜尋與篩選

  • 搜尋框：打字即時過濾，右邊 X 可清空
  • Campaign 下拉：只看某活動的連結
  • 狀態 Chip：啟用 / 暫停 / 已封存
  • 排序：最新 / 最舊 / 最多點擊 / 最少點擊
  • 標籤下拉：只看某個標籤
  • 建立者下拉：只看某位同事建的連結，選項後面的數字是他建了幾條

匯出 CSV

頁首「匯出」會下載目前狀態篩選下的連結清單，包含短網址、目的網址、點擊數、UTM 五欄、標籤、建立者、建立與到期時間。要統計「誰建了幾條、哪些連結點擊最多」，直接用 Excel 或 Google 試算表的樞紐分析即可。

哪些點擊不算進數據？

用「測試短網址」或點列表上的短碼開啟的點擊，會標成「測試」，點擊數只算真實流量。直接複製短網址貼到瀏覽器開，會被算成一般點擊，自己測試請用前兩種方式。社群平台抓預覽的爬蟲、搜尋引擎等機器人也不會被記錄。

企業郵件的安全掃描（收信時自動打開信裡每個連結的機器）也會被排除，標成「疑似郵件掃描點擊」。B2B 名單的 EDM，這類點擊可能佔一半以上，排除後的數字才是真人。數據分析頁和活動頁上方可以勾「含測試與疑似機器點擊」，把它們加回來看。

為什麼要按「同步」按鈕？

這個工具用 client-side cache — 切頁不重新抓 DB，所以極快。代價是建立 / 修改後要手動按同步才會看到最新列表。頁首右上角淡藍色「同步」鍵旁邊會顯示「最後同步於 X 分鐘前」。

建立 / 複製 / 暫停 / 刪除等操作已內建強制同步，不用手動按；但如果你另外開分頁操作，回來這頁就需要按一下。

建立連結進階選項

除了基本三欄，展開進階可看到以下選項。

標籤 (Tags)

自由分類。建議先跟團隊對齊一組核心標籤（例：常態 / 節慶 / KOL / 展場），避免每個人自創。

UTM 模板（選填）

UTM 區塊最上方可以選一個既有模板，source / medium / content 會自動帶入，省重複打字。不選也完全可以，直接在下方選媒介和來源即可。

自訂短碼 (custom code)

想要 /spring-2026 而不是隨機 /Ab3xK9p：

  • 3–50 字元
  • 只能用英文字母、數字、-、_
  • 系統即時查重

不填就會自動產 7 碼隨機碼。

排程啟用 (startsAt)

「幾月幾日幾點才開始生效」。之前點會導到「尚未開始」頁。用途：EDM 提前埋好連結，排程當天自動生效。

過期時間 (expiresAt)

「幾月幾日後失效」。過期點擊會導到「連結已過期」頁。用途：限時活動、優惠碼。

點擊上限 (maxClicks)

超過指定次數後連結失效。用途：限量優惠、內測名額。

允許國家 (allowedCountries)

多選列表，只允許這些國家的流量進來。其他國家導到「地區不允許」頁。用途：地區限定活動、版權限制。

A/B 變體

一條短網址後掛多個目的地 URL 加權重：

code: spring-26 variant A: landing-v1.html weight: 50 variant B: landing-v2.html weight: 50

使用者點時加權隨機分流。後台看「哪個 variant 贏」。

302 vs 301 轉址

  • 302（預設，暫時轉址） — 行銷連結就用這個，SEO 不會傳遞
  • 301（永久轉址） — 只在做永久網站搬家時用

社群分享預覽

短網址貼到 Facebook、LINE、LinkedIn、Threads 時，平台會抓一張「預覽卡片」（標題、描述、圖片）。預設抓的是目的頁面自己的內容，但常常不理想：

  • LinkedIn 公司頁抓到的是「LinkedIn Login, Sign in」
  • Google 文件、雲端硬碟抓到「JavaScript isn't enabled in your browser」
  • 同一個網頁要針對不同活動放不同標語

怎麼設定

  1. 連結管理 → 該列 ⋮ → 編輯連結
  2. 展開「社群分享預覽」
  3. 填預覽標題、預覽描述、預覽圖片網址（任一欄留空就沿用目的頁原本的內容）
  4. 右邊會即時顯示卡片長相 → 儲存

圖片要填公開可存取的圖片網址，建議 1200 × 630 px（1.91:1）。目前不支援直接上傳檔案。這個設定只在「編輯連結」裡，建立新連結時沒有 —— 先建好、看過系統自動抓的預覽，不滿意再改。

已經分享出去的貼文要手動刷新

各平台會快取預覽卡片。如果連結早就貼出去了，改完後要到 Facebook Sharing Debugger（Threads、LINE 也適用）或 LinkedIn Post Inspector 貼上短網址，按「重新抓取」才會換成新卡片。

只有社群平台的預覽爬蟲會看到自訂內容；真人點擊照樣直接轉址到目的網址，UTM 與點擊統計都不受影響。有設自訂預覽的連結，即使同時設了「允許國家」，海外機房的平台爬蟲也能正常抓到卡片。

垃圾桶與還原

刪除的連結不會真的消失，會移到垃圾桶：

  • 入口：連結管理頁首的「垃圾桶」按鈕
  • 在垃圾桶期間：短網址停止運作（點了會顯示找不到頁面），點擊也不再累積
  • 還原：按「還原」就回到連結列表，短網址、設定、過去的點擊紀錄都和刪除前一樣
  • 誰能還原：連結的建立者，或工作區的 OWNER / ADMIN（其他人在那一列看不到還原按鈕）
刪除還是暫停？

只是暫時不想讓人點 → 用暫停，點擊的人會看到「連結已停用」頁，連結還留在列表裡。確定不要了、想讓列表乾淨 → 用刪除，萬一刪錯再到垃圾桶救回來。

Campaign 管理（/campaigns）

什麼是 Campaign？

一場行銷活動 — 例如「2026 春季新品發表」。一場活動會有多條連結（EDM、FB 廣告、KOL 貼文、QR 傳單…），都指到同一個 utm_campaign 值。

Campaigns 頁做什麼？

  • 排行榜：所有活動的績效排行 — 負責人、狀態（依活動期間自動顯示）、點擊數、7 天趨勢、最後活動時間、目標達成率（含進度參考線）；可以依負責人和狀態篩選：進行中 / 即將開始 / 已結束 / 已封存
  • 負責人摘要卡（上方）：每人幾檔進行中、幾檔達標、幾檔落後（見下方「負責人」）
  • 勾選 2–4 個活動：疊圖比較 / 進入並列比較頁（見下方「比較活動」）
  • Orphan Links：有 utm_campaign 值但還沒綁到任何 Campaign 的連結（通常是舊資料）

活動期間

每個活動可以設定開始日和結束日：進入活動頁 → 活動名稱下方的日期列 → 鉛筆（還沒設定時顯示「設定期間」）。

  • 用台灣時間計算，頭尾兩天都包含；可以只填其中一個（例如只填開始日 = 持續中）
  • 設定後，活動列表、活動頁的數字和目標進度都只算這段期間內的點擊
  • 沒設期間的活動，一律看全部期間
建議活動一建立就設期間

展會活動可以從第一封預告信寄出那天，算到展後感謝信寄出後兩週。

狀態與封存

狀態依日期自動判斷，不用手動切換：

  • 即將開始 — 還沒到開始日
  • 進行中 — 在期間內，或沒有設期間
  • 已結束 — 過了結束日

封存是唯一要手動設定的狀態：活動頁右上角的盒子圖示。封存後活動會從列表收起來（篩選「已封存」才看得到），短網址照常轉址、照常記錄點擊，隨時可以取消封存。想把舊活動收起來就用封存，不要用刪除。

負責人

每個活動可以指定一位負責人，這檔活動的成效就算在他的 KPI 上。進入活動頁 → 活動名稱下方「負責人」→ 從工作區成員中選（也可以選「未指派」）。更換會寫進操作紀錄。

  • 只能選工作區成員；同事要先被邀請進工作區才選得到
  • 活動列表有「負責人」欄，沒指派的會顯示灰字「未指派」，提醒大家補上
  • 用「建立者」當負責人並不準：活動常常是在建第一條連結時自動產生的，建立者只是剛好建了那條連結的人
負責人摘要卡（活動列表上方）

每位負責人一張，顯示「進行中 N 檔 · 共 M 檔」「達標 X / Y」「落後進度 Z 檔」，點卡片就只看那個人的活動，再點一次取消。卡片刻意不加總點擊數：EDM 活動和展會 QR 活動的點擊量差上百倍，加總只會比出通路，不是比人。

列表工具列也有負責人篩選：所有負責人 / 我的活動 / 未指派 / 各成員。

單活動駕駛艙 /campaigns/[name]

點活動名稱進入該活動的指揮中心，有 3 個 tab：

  • 總覽 — 目標進度 + 點擊趨勢
  • 流量 — 可以點選下鑽的流量拆解
  • 連結 — 這場活動底下的所有連結，可以逐條展開

總覽和流量右邊可以切 活動期間 / 全部期間 / 90 天 / 30 天。有設活動期間時預設看「活動期間」，沒設就看全部期間 —— 跟活動列表的預設一樣，所以兩邊的數字對得上。上方的點擊數、平均點擊也跟著這個期間走。

流量分頁：點一下就篩選

來源、媒介、內容 (Content)、主要連結、國家、來源網站，點任何一項就會篩選，整頁的數字、每日圖和其他清單都會跟著變，上方會顯示「N 次點擊 · 佔整個活動 X%」。條件可以疊加，例如「來源：linkedin」再加「國家：JP」。上方的篩選標籤點 ✕ 移除，或按「清除篩選」。

來源網站已經依網站合併（例如所有 Mailchimp 的網址併成一列「Mailchimp」），點進去會列出實際的來源頁網址。大部分 Email、QR、App 內的點擊不會帶來源網站，會歸在「（無來源網站）」—— 看通路請看來源 / 媒介。

連結分頁：點一列展開
  • 每條連結下方顯示目的網址
  • 「走勢（全期間）」：從活動第一次點擊到今天的迷你走勢，所有列用同一個刻度，旁邊是高峰日（例：高峰 6/6 · 132）
  • 點一列就地展開：點擊數、不重複訪客、第一次 / 最後一次點擊、高峰日、每日走勢、國家 / 來源網站 / 裝置。展開後可以按「在流量分頁只看這條連結」
  • 按齒輪編輯連結，存檔後會回到活動頁

頁首的按鈕：

  • 新增連結 — 打開建立表單時已經帶入這個活動，只要填網址和通路
  • 分享報告 — 產生給主管 / 合作夥伴看的唯讀報告，見公開分享報告
  • 複製所有連結 — 一次複製這個活動的全部短網址
  • 封存（盒子圖示）— 見上方「狀態與封存」
Campaign 自動建立

填 utm_campaign = "spring_sale_2026" → 系統自動 upsert 一筆 Campaign row（status=ACTIVE）。不用先跑去 Campaigns 頁手動建才能填 UTM。直接建連結，Campaign 會自己出現在列表。

目標 (Goal)

在總覽分頁的目標卡按鉛筆設定，有兩種方式：

  • 總數：整個活動一個目標點擊數
  • 依通路（建議）：每個媒介（email / social / qr…）各填一個數字，總目標自動加總。目標卡會顯示「總計」加上每個通路各一條進度條；有點擊但沒設目標的通路另外列出（點擊仍算進總數）

為什麼建議依通路：只設總數時，EDM 表現好會把 QR 的落後蓋過去，看不出該調整哪個通路。

進度參考線

活動「進行中」且有開始日和結束日時，每條進度條上會有一條灰色直線，代表照時間平均分配、今天應該到的位置，旁邊寫「超前進度 N」或「落後進度 N · 照進度應有 M」；落後的進度條會變橘色。活動列表的目標欄也有同樣的參考線（滑鼠移上去會顯示今天應達幾 %）。

參考線是平均分配。展會這類點擊集中在 EDM 寄出日和展期的活動，前期看起來「落後」很正常，之後會追上。

達成率一律用活動期間內的點擊計算（沒設期間就是全部期間），不會因為你切到 30 天就變少；活動列表的目標欄用同一個算法。超過目標會照實顯示（例：130%）。

活動列表的期間

活動列表上方可以切 活動期間 / 7 天 / 30 天 / 90 天 / 全部期間，預設是「活動期間」：每個活動各自算自己的期間。

比較活動

在活動列表勾選 2–4 個活動 →「並列詳細比較」。

  • 期間一樣可以切活動期間 / 全部期間 / 7d / 30d / 90d
  • 每日點擊圖有兩種看法：依日期（實際日期）、對齊開始日（第 0 天 = 各活動的開始日，沒設期間就用第一次點擊那天；開始日之前的預熱點擊顯示成負的天數）。比較在不同月份舉辦的展會時用「對齊開始日」
  • 折線、圖例和下方欄位用同一組顏色

UTM 模板（選用）

不用模板也完全可以

模板只是捷徑：把常用通路的媒介 / 來源 / 內容存起來，建連結時一鍵帶入，省得重打、也讓大家的拼法一致。不用的話，建立連結時直接在 UTM 區塊選媒介和來源就好。適合同一個通路會反覆建連結的情況，例如每週 EDM、每場展會的攤位 QR。

設計理念：通路預設

一個模板 = 某個通路 / 素材類型的 UTM 預設組合：

模板名稱sourcemediumcontent
EDM 電子報newsletter_weeklyemailtop_banner
FB 付費廣告facebookcpc—
展場 QRflyer_computexqr—
刻意沒有 campaign 欄位

因為同一個通路會橫跨多個活動使用，campaign 每次建連結時現填。

使用流程

兩種用法擇一：在模板頁按該模板的「使用」，會直接打開已套用模板的建立表單；或在建立表單的 UTM 區塊選模板。

  1. 選模板
  2. 系統自動帶入 source / medium / content / term
  3. 你只需填 campaign
  4. 儲存

模板管理

左側選單下方（「設定」上面）→ UTM 模板 → 新增 / 編輯 / 刪除。有某個通路你常常重複建連結時再建模板就好，不需要一開始就把每個通路都建一個。

數據分析（/analytics）

定位

這頁是全站跨維度分析，不是活動級排行（那是 Campaigns 頁的事）。

主要分析維度

  • 時間軸 — 每日 / 小時的點擊趨勢
  • 裝置 / 瀏覽器 / OS — 流量組成
  • 地區 / 城市 — 地理分佈
  • 來源 / 媒介 / 來源網站 — 流量來源（來源網站已依網站合併，例如 Mailchimp、LinkedIn）
  • UTM 交叉表 — 例如 source × medium 組合，哪組帶最多量

篩選器

  • 時段：24h / 7d / 30d / 90d / 全部期間 / 自訂（自訂的起訖日都包含當天）
  • 指定單一連結（在連結列表點點擊數，或 ⋮ → 數據分析，會直接帶入並預設全部期間）
  • 指定單一 Campaign / 標籤

系統保留最近約兩年的點擊資料可在這裡分析。

為什麼這裡的數字跟列表不一樣？

連結列表的點擊數是從建立到現在的累計；這頁只算你選的期間。要對得上，時段選「全部期間」。

匯出與分享

  • 匯出 — 下載的 CSV 就是你畫面上篩選的範圍（期間、活動、標籤、連結都會套用），每筆點擊附上 UTM 活動 / 來源 / 媒介 / 內容，可以直接拿去樞紐分析
  • Share report — 把目前畫面的範圍做成分享報告，見公開分享報告

點擊熱度圖

星期 × 小時的熱度分佈，找使用者最常點擊的時段，排 EDM 發送時間或社群貼文時間用。

為什麼沒有轉換率 / CVR 欄位？

團隊目前不用轉換追蹤 snippet。DB 與 API 都還在，哪天要啟用，把 UI 加回即可。

QR Code

每條連結都能產 QR code，三個地方都拿得到：

  • 連結列表：短碼旁邊的 QR 圖示（⋮ 選單裡的「QR Code」也行），會在那一列下方展開
  • 剛建立完：建立成功的畫面直接顯示 QR
  • 手機版：短網址右邊的 QR 按鈕

下載格式：

  • PNG — 1024 × 1024 px，海報、DM 都夠清楚
  • SVG — 真正的向量圖，放大不失真，給設計師排版或大型輸出用

兩種都有中央的 EnGenius logo，檔名會用連結標題（例：qr-Computex-海報.png）。

QR 跟短網址綁定 — 之後改目的地，原本掃出來的人也會跟著去新目的地。

適用場景

  • 實體傳單 / DM
  • 展場 KV 海報 / 拉頁
  • 名片
  • 產品包裝導流

一次建很多條

連結管理右上角「+ 建立新連結」旁邊的 ▾ 有三種批次方式，選單上也有一句說明：

方式什麼時候用
批次建立同一個目的網址、多個版本（例如每位 KOL、每則貼文各一條，用 utm_content 區分）
CSV 匯入每一列各自的目的網址與 UTM，一次建幾十條（例：發給各國代理商）
活動啟動器展會、新品上市：一步一題的引導頁，一次建好整套通路連結，並設好期間、負責人、目標

活動啟動器（展會 / 新品上市）

行銷活動 → 活動啟動器（或連結管理「建立新連結」旁的 ▾）。一步一題的引導頁，6 步建好整個活動，不用自己打任何 UTM：

  1. 活動類型：展會 / 新品上市（電商促銷即將推出）
  2. 基本資訊：活動名稱（例：ISE 2027，系統自動產生追蹤名稱 ise_2027，可修改）、活動期間、負責人。也可以選「幫既有活動補連結」
  3. 目的網址：主要的活動頁或產品頁。活動頁還沒上線的話，勾「活動頁還沒上線」先填官網，這些連結會加上「待換活動頁」標籤，等頁面上線後在連結列表篩選出來一次改好（短網址不變）
  4. 通路：依時程分組（展會：展前宣傳 / 現場 QR / 展後追蹤；新品：發表 / 第二波追蹤），勾選這次會用的。同一個通路要發好幾則就按「再加一則」；現場 QR 可以各自指定要導去哪（例如 Demo 區導到 Craft AI）
  5. 目標：依通路填目標。系統會帶入「過去同通路每則平均點擊 × 則數」當參考值，可以一鍵套用，也可以略過
  6. 確認建立：逐列檢查標題、內容、短碼、目的網址，都可以直接改。短碼會即時檢查（被用過、清單內重複會標紅框）；按「建立」一次建好，活動期間、負責人、各通路目標也一起設好

系統自動套用的規則：EDM 一律用 mailchimp、社群以 LinkedIn 為主、短碼是好讀的格式（例：ise27-booth，印在海報上別人也能手動輸入），並依階段加上標籤（展前 / 現場QR / 展後 / 發表 / 追蹤）。

部分失敗也沒關係

例如某個短碼剛好被別人用掉，那一列會顯示原因，其他照常建立。改好後按「重試」只會建失敗的那幾條，不會重複。

多國市場、電商促銷，或手上只有一份長篇企劃？

用「活動規劃 skill」（給 Claude / Codex 等 AI 助理用），問答後產出 CSV 匯入檔和一頁成效衡量計畫，再用下方的 CSV 匯入。

CSV 匯入

建立新連結旁的 ▾ → CSV 匯入 → 上傳 CSV → 看前 5 列預覽 → 匯入 → 逐列顯示成功或失敗原因。

欄位名稱要用小寫加底線

例如 original_url、utm_source，不能寫成 originalUrl、utmSource，否則會整批匯入失敗。最保險的做法：在匯入頁按 Download template 下載範本，直接在上面填。

original_url,title,custom_code,utm_source,utm_medium,utm_campaign,utm_content,tags,starts_at https://www.engeniustech.com/en/promo,Spring EDM Top,spring-edm-top,newsletter,email,spring_sale_2026,top_banner,EDM,2026-03-03T09:00:00+08:00 https://www.engeniustech.com/en/promo,Spring FB Ad,,facebook,cpc,spring_sale_2026,video_30s,"FB,付費",
欄位說明
original_url（必填）目的網址，要 http(s):// 開頭
title連結標題
custom_code自訂短碼；留空自動產生
utm_source / utm_medium / utm_campaign / utm_content / utm_termUTM 五個欄位；source / medium 會照 UTM 白名單檢查
tags標籤，多個用逗號分隔（整格要加雙引號，例 "FB,付費"）；不存在的標籤會自動建立
starts_at / expires_at排程啟用 / 到期時間，ISO 格式，例 2026-03-03T09:00:00+08:00
max_clicks點擊上限（正整數）
allowed_countries只允許的國家，兩碼代號用逗號分隔，例 "US,DE"
redirect_typeTEMPORARY（預設，302）或 PERMANENT（301）
  • 一次最多 500 列；欄位順序可以自己調，只要名稱對
  • 某一列有錯（網址格式、短碼重複、不符白名單）只會跳過那一列，其他列照常建立
  • 每列都是獨立 UTM（不共用 template），因為同一批通常是同通路不同素材

批次建立

建立新連結旁的 ▾ → 批次建立。填一個目的網址和共同的 UTM，再列出多個 content，一次產生多條。完成後可以一次複製全部短網址，或一次下載全部 QR（每張 1024 px）。

公開分享報告

想把成效給沒有帳號的人看（主管、合作夥伴、客戶）？產生一個唯讀的分享連結。

從哪裡產生

  • 活動詳情頁 → 頁首「分享報告」：分享這個活動，期間跟你頁面上選的一樣（活動期間 / 全部期間 / 90 天 / 30 天）
  • 數據分析頁 → 頁首「Share report」：分享目前畫面的範圍（選了單一連結就分享那條、選了活動就分享那個活動，什麼都沒選就是整個工作區）

報告會固定日期

產生時，報告就固定成當下畫面上的日期（例：2026-05-01 – 2026-06-30）或「全部期間」。主管下週再打開，看到的還是同一段期間的數字，不會因為日子往前滾而改變。

可以設定

  • 分享連結有效期：7 / 30 / 90 天或自訂天數，過期就打不開
  • 密碼（選填）
  • 最大瀏覽次數（選填）

對方看到什麼

  • 總點擊數、每日點擊
  • 通路表現：各媒介、各來源各帶來多少點擊
  • 連結排行：哪幾條連結點擊最多
  • 裝置、瀏覽器、國家
  • 活動報告的副標會顯示負責人（只有名字）

報告只算真實流量（不含內部測試點擊和疑似郵件掃描點擊），預設中文，右上角可以切英文。對方只能看、不能編輯，也看不到其他活動。

工作區 (Workspace)

一個工作區 = 一組連結 + 活動 + 成員 + UTM 規範。

大部分團隊只需要一個（例：HQ MKT）。如果之後要分區（台灣 / 日本）或跨團隊（行銷 / 客服），再開新工作區。

切換工作區在左上角的選擇器。

邀請同事

OWNER / ADMIN 到「設定 → 成員」產生邀請連結（不會自動寄信），自己貼到 Slack 或 Email 給對方。對方點開、用 Google 帳號登入就會自動加入工作區。邀請連結 7 天後失效，過期可以重發。

UTM 白名單治理

設定 → UTM 規範 分頁（只有 OWNER / ADMIN 看得到、能改）

可設定的項目

  • Approved Sources — 允許的 source 值清單
  • Approved Mediums — 允許的 medium 值清單

設定後的效果

  • 團隊成員建連結時輸入非白名單值 → 欄位下方即時出現黃色提醒
  • 儲存時會被擋下，要改成白名單內的值才能建立；真的需要新值，請 OWNER / ADMIN 先加進白名單
  • 白名單留空 = 不限制
目的

避免同一個來源 10 個人寫出 10 種拼法（facebook / Facebook / FB / fb / meta…）導致 GA 報表無法彙總。

常見問題

  • Q. 短網址會失效嗎？不會 — 除非你主動暫停或刪除、設過期時間、或設點擊上限。
  • Q. 我可以換短網址的目的地嗎？可以。編輯連結 → 改「原始網址」→ 儲存。原本分享出去的短網址下次點擊會去新目的地。
  • Q. 為什麼建完連結、回到列表看不到？曾經有這個 bug，現在修好了 — 建立 / 複製 / 刪除等操作都會強制同步。如果偶爾還是遇到，按頁首淡藍色「同步」按鈕。
  • Q.「建立副本」跟「複製短網址」差別？建立副本 = 在 DB 新增一條同設定的連結（不同 short code），用於 A/B 測試或跨通路重用；複製短網址 = 把短網址複製到剪貼簿，用於貼到 EDM / 社群。
  • Q. 我建的連結同事看得到嗎？同工作區的成員都看得到（協作用）。需要私人連結目前不支援。
  • Q. 怎麼撤銷一個已發出去的短網址？暫時撤銷 → 編輯 → 狀態改「暫停」（點擊會導到「連結已停用」頁）；不再使用 → 刪除（會進垃圾桶，刪錯還能還原）。
  • Q. 可以追蹤 landing page 之後的行為嗎？不行 — 這工具只追「點擊前」。Landing 後用 GA4。見 UTM 指南的分工定位章節。
  • Q. 輸入非白名單的 source / medium 會怎樣？欄位下方會出現黃色提醒，而且儲存時會被擋下。改用白名單裡的值；如果確實需要新值，請 OWNER / ADMIN 加進白名單後再建。
  • Q. 有點擊是 bot / 爬蟲嗎？會影響統計嗎？不會。系統會依瀏覽器識別（User-Agent）排除爬蟲，包括 Facebook、LINE、LinkedIn 抓預覽的爬蟲和搜尋引擎，這些都不記錄。另外 2 秒內同一 IP 重複點同一條連結只算一次。企業信箱的安全掃描比較難從瀏覽器識別認出來，系統用另一條規則把它們標成「疑似郵件掃描點擊」並排除。
  • Q. 為什麼 EDM 的點擊數比以前少？2026-11 起排除了「疑似郵件掃描點擊」，舊資料也一併重算。以 Interop / Computex 為例，EDM 點擊有一半以上是企業信箱的安全掃描開的，不是真人。想看原本的數字，在數據分析頁或活動頁勾「含測試與疑似機器點擊」。
  • Q. 怎麼看每個人負責的活動成效？活動列表上方的負責人摘要卡：每人幾檔進行中、幾檔達標、幾檔落後進度，點卡片就只看那個人的活動。前提是每個活動都指定了負責人（活動頁名稱下方）。
  • Q. 活動結束了要刪掉嗎？不用。設好結束日，活動會自動顯示「已結束」；想從列表收起來就按封存，短網址和點擊紀錄都不受影響。
  • Q. 我自己點來測試，會灌水數據嗎？用「測試短網址」或點列表上的短碼開啟就不會，這兩種會標成「測試」、不算進點擊數。但直接複製短網址貼到瀏覽器開，會被當成一般點擊。
  • Q. 分享到 FB / LINE 的預覽圖不對怎麼辦？到「編輯連結 → 社群分享預覽」自訂標題和圖片，再用 Facebook Sharing Debugger 重新抓取。見社群分享預覽。
  • Q. 不小心刪錯連結怎麼辦？連結管理 → 垃圾桶 → 還原，短網址和點擊紀錄都會回來。
  • Q. 列表上有幾百次點擊，點進數據分析卻是 0？數據分析只算你選的期間，列表是累計。把時段切到「全部期間」就對得上（從列表點點擊數進去時，預設就是全部期間）。
  • Q. 下載的 QR 夠印海報嗎？夠。PNG 是 1024 × 1024 px；要更大的輸出用 SVG（向量，怎麼放大都清楚）。
  • Q. 傳給主管的報告，數字會一直變嗎？不會。分享報告在產生時就固定了日期範圍，之後再打開都是同一段期間。
